BEAGLEPLAY TCP SERIAL BRIDGE
Complete Installation, Configuration, Testing, Operation and Rollback Guide
=========================================================================

PURPOSE
-------
This document is the permanent reference for the BeaglePlay GNSS and MCU
serial bridge services.

The production design uses ONE common C executable:

    /usr/local/bin/tcp_serial_bridge

The same executable is started twice by systemd:

    1) GNSS/K803
       Service : serial-bridge.service
       TCP     : 2000
       UART    : /dev/ttyS0
       Baud    : 115200
       User    : root

    2) MCU
       Service : mcu_server.service
       TCP     : 2001
       UART    : /dev/ttyS3
       Baud    : 115200
       User    : debian

The bridge is intentionally transparent:

    TCP -> UART
    UART -> TCP

It does not interpret GNSS or MCU commands, does not assume one-line or
multi-line replies, and does not implement application-level command
synchronization.

The Java application is responsible for the application protocol and
command/response coordination.

IMPORTANT:
The exact source code that is deployed to production must always be kept in
version control. The source included in this document is a reference
implementation matching the deployed interface and design. If the project's
validated source differs, the validated project source is authoritative.

=========================================================================
2. WHY THE SAME PROGRAM IS USED TWICE
=========================================================================

Linux permits multiple independent processes to execute the same binary.

GNSS instance:

    /usr/local/bin/tcp_serial_bridge 2000 /dev/ttyS0

MCU instance:

    /usr/local/bin/tcp_serial_bridge 2001 /dev/ttyS3

The executable is the same, but each process has its own:

    TCP listening socket
    UART file descriptor
    client list
    threads
    process ID

Therefore the two services are independent.

6. EXPLANATION OF THE SERVICE FILES
=========================================================================

[Unit]
    Describes startup ordering and dependencies.

Description=
    Human-readable name shown by systemctl.

After=
    Tells systemd to start this service after the specified target.

Wants=
    Requests activation of the specified target.

[Service]
    Defines the actual program to run.

Type=simple
    The ExecStart process is the main service process.

ExecStart=
    The exact command executed by systemd.

GNSS:

    /usr/local/bin/tcp_serial_bridge 2000 /dev/ttyS0

MCU:

    /usr/local/bin/tcp_serial_bridge 2001 /dev/ttyS3

Restart=always
    If the program exits, systemd starts it again.

RestartSec=2
    Wait two seconds before restarting.

User=root
    GNSS bridge runs as root, matching the original service.

User=debian
    MCU bridge runs as debian, matching the original service.

WorkingDirectory=/usr/local/bin
    Sets the process working directory.

StandardOutput=journal
StandardError=journal
    Sends stdout/stderr to systemd journal.

[Install]
WantedBy=multi-user.target
    Allows the service to be enabled for normal boot.

7. REFERENCE C SOURCE
=========================================================================

The following is a complete transparent bridge implementation.

Command syntax:

    tcp_serial_bridge <TCP_PORT> <SERIAL_DEVICE>

Examples:

    ./tcp_serial_bridge 2000 /dev/ttyS0

    ./tcp_serial_bridge 2001 /dev/ttyS3

Design:

    - maximum 8 TCP clients
    - one TCP listening socket
    - one serial port
    - serial -> all connected TCP clients
    - TCP -> serial
    - mutex protects serial writes
    - no command parsing
    - no line parsing
    - no artificial 200 ms command collection
    - no artificial 2000 ms response timeout
    - no application protocol synchronization

SOURCE:

-----------------------------------------------------------------------

#define _GNU_SOURCE

#include <arpa/inet.h>
#include <errno.h>
#include <fcntl.h>
#include <netinet/in.h>
#include <pthread.h>
#include <signal.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/socket.h>
#include <termios.h>
#include <unistd.h>

#define MAX_CLIENTS 8
#define BUFFER_SIZE 4096
#define BAUD_RATE B115200

typedef struct {
    int fd;
    int active;
} client_t;

typedef struct {
    int client_index;
    int serial_fd;
} client_context_t;

static client_t clients[MAX_CLIENTS];
static pthread_mutex_t clients_mutex = PTHREAD_MUTEX_INITIALIZER;
static pthread_mutex_t serial_write_mutex = PTHREAD_MUTEX_INITIALIZER;

static volatile sig_atomic_t running = 1;

static void handle_signal(int sig)
{
    (void)sig;
    running = 0;
}

static void remove_client(int index)
{
    pthread_mutex_lock(&clients_mutex);

    if (index >= 0 &&
        index < MAX_CLIENTS &&
        clients[index].active) {

        close(clients[index].fd);
        clients[index].fd = -1;
        clients[index].active = 0;
    }

    pthread_mutex_unlock(&clients_mutex);
}

static int add_client(int fd)
{
    int index = -1;

    pthread_mutex_lock(&clients_mutex);

    for (int i = 0; i < MAX_CLIENTS; i++) {

        if (!clients[i].active) {

            clients[i].fd = fd;
            clients[i].active = 1;

            index = i;
            break;
        }
    }

    pthread_mutex_unlock(&clients_mutex);

    return index;
}

static int open_serial(const char *device)
{
    int fd = open(device, O_RDWR | O_NOCTTY | O_NONBLOCK);

    if (fd < 0) {
        fprintf(stderr,
                "[ERROR] Cannot open serial device %s: %s\n",
                device,
                strerror(errno));
        return -1;
    }

    struct termios tty;

    if (tcgetattr(fd, &tty) != 0) {

        fprintf(stderr,
                "[ERROR] tcgetattr(%s): %s\n",
                device,
                strerror(errno));

        close(fd);
        return -1;
    }

    cfmakeraw(&tty);

    cfsetispeed(&tty, BAUD_RATE);
    cfsetospeed(&tty, BAUD_RATE);

    tty.c_cflag |= CLOCAL | CREAD;
    tty.c_cflag &= ~CSTOPB;
    tty.c_cflag &= ~PARENB;
    tty.c_cflag &= ~CRTSCTS;
    tty.c_cflag &= ~CSIZE;
    tty.c_cflag |= CS8;

    tty.c_cc[VMIN] = 0;
    tty.c_cc[VTIME] = 1;

    if (tcsetattr(fd, TCSANOW, &tty) != 0) {

        fprintf(stderr,
                "[ERROR] tcsetattr(%s): %s\n",
                device,
                strerror(errno));

        close(fd);
        return -1;
    }

    return fd;
}

static int create_server(int port)
{
    int server_fd;
    int option = 1;

    server_fd = socket(AF_INET, SOCK_STREAM, 0);

    if (server_fd < 0) {
        perror("[ERROR] socket");
        return -1;
    }

    if (setsockopt(server_fd,
                   SOL_SOCKET,
                   SO_REUSEADDR,
                   &option,
                   sizeof(option)) < 0) {

        perror("[ERROR] setsockopt");
        close(server_fd);
        return -1;
    }

    struct sockaddr_in address;

    memset(&address, 0, sizeof(address));

    address.sin_family = AF_INET;
    address.sin_addr.s_addr = htonl(INADDR_ANY);
    address.sin_port = htons(port);

    if (bind(server_fd,
             (struct sockaddr *)&address,
             sizeof(address)) < 0) {

        fprintf(stderr,
                "[ERROR] bind port %d failed: %s\n",
                port,
                strerror(errno));

        close(server_fd);
        return -1;
    }

    if (listen(server_fd, MAX_CLIENTS) < 0) {

        perror("[ERROR] listen");
        close(server_fd);
        return -1;
    }

    return server_fd;
}

static void broadcast_to_clients(const char *buffer, ssize_t length)
{
    pthread_mutex_lock(&clients_mutex);

    for (int i = 0; i < MAX_CLIENTS; i++) {

        if (!clients[i].active)
            continue;

        ssize_t sent = send(clients[i].fd,
                            buffer,
                            length,
                            MSG_NOSIGNAL);

        if (sent < 0) {

            if (errno == EPIPE ||
                errno == ECONNRESET ||
                errno == ENOTCONN) {

                close(clients[i].fd);
                clients[i].fd = -1;
                clients[i].active = 0;
            }
        }
    }

    pthread_mutex_unlock(&clients_mutex);
}

static void *serial_reader_thread(void *argument)
{
    int serial_fd = *(int *)argument;

    char buffer[BUFFER_SIZE];

    while (running) {

        ssize_t n = read(serial_fd,
                         buffer,
                         sizeof(buffer));

        if (n > 0) {

            /*
             * Anything received from the hardware is sent to every
             * currently connected TCP client.
             */
            broadcast_to_clients(buffer, n);

        } else if (n < 0) {

            if (errno != EAGAIN &&
                errno != EWOULDBLOCK &&
                errno != EINTR) {

                fprintf(stderr,
                        "[ERROR] Serial read failed: %s\n",
                        strerror(errno));

                break;
            }
        }

        usleep(1000);
    }

    return NULL;
}

static void *client_thread(void *argument)
{
    client_context_t *context =
        (client_context_t *)argument;

    int index = context->client_index;
    int serial_fd = context->serial_fd;

    free(context);

    char buffer[BUFFER_SIZE];

    while (running) {

        ssize_t n = recv(clients[index].fd,
                         buffer,
                         sizeof(buffer),
                         0);

        if (n > 0) {

            /*
             * Multiple client threads can receive TCP data at the same
             * time. The physical UART is shared, therefore serial writes
             * are protected by a mutex.
             *
             * This prevents two write() operations from interleaving.
             */
            pthread_mutex_lock(&serial_write_mutex);

            ssize_t offset = 0;

            while (offset < n) {

                ssize_t written =
                    write(serial_fd,
                          buffer + offset,
                          (size_t)(n - offset));

                if (written > 0) {
                    offset += written;
                    continue;
                }

                if (written < 0 && errno == EINTR)
                    continue;

                if (written < 0 &&
                    (errno == EAGAIN ||
                     errno == EWOULDBLOCK)) {

                    usleep(1000);
                    continue;
                }

                fprintf(stderr,
                        "[ERROR] Serial write failed: %s\n",
                        strerror(errno));

                break;
            }

            pthread_mutex_unlock(&serial_write_mutex);

        } else if (n == 0) {

            break;

        } else {

            if (errno == EINTR)
                continue;

            break;
        }
    }

    printf("[INFO] Client %d disconnected\n", index);

    remove_client(index);

    return NULL;
}

static void close_all_clients(void)
{
    pthread_mutex_lock(&clients_mutex);

    for (int i = 0; i < MAX_CLIENTS; i++) {

        if (clients[i].active) {
            close(clients[i].fd);
            clients[i].fd = -1;
            clients[i].active = 0;
        }
    }

    pthread_mutex_unlock(&clients_mutex);
}

int main(int argc, char *argv[])
{
    if (argc != 3) {

        fprintf(stderr,
                "Usage: %s <TCP_PORT> <SERIAL_DEVICE>\n",
                argv[0]);

        fprintf(stderr,
                "Example: %s 2000 /dev/ttyS0\n",
                argv[0]);

        fprintf(stderr,
                "Example: %s 2001 /dev/ttyS3\n",
                argv[0]);

        return EXIT_FAILURE;
    }

    int port = atoi(argv[1]);

    if (port <= 0 || port > 65535) {

        fprintf(stderr,
                "[ERROR] Invalid TCP port: %s\n",
                argv[1]);

        return EXIT_FAILURE;
    }

    const char *serial_device = argv[2];

    signal(SIGINT, handle_signal);
    signal(SIGTERM, handle_signal);
    signal(SIGPIPE, SIG_IGN);

    printf("[INFO] ================================\n");
    printf("[INFO] TCP Serial Bridge\n");
    printf("[INFO] TCP port       : %d\n", port);
    printf("[INFO] Serial device  : %s\n", serial_device);
    printf("[INFO] Baud rate      : 115200\n");
    printf("[INFO] Maximum clients: %d\n", MAX_CLIENTS);
    printf("[INFO] Mode           : transparent\n");
    printf("[INFO] ================================\n");

    for (int i = 0; i < MAX_CLIENTS; i++) {
        clients[i].fd = -1;
        clients[i].active = 0;
    }

    int serial_fd = open_serial(serial_device);

    if (serial_fd < 0)
        return EXIT_FAILURE;

    int server_fd = create_server(port);

    if (server_fd < 0) {
        close(serial_fd);
        return EXIT_FAILURE;
    }

    pthread_t serial_thread;

    if (pthread_create(&serial_thread,
                       NULL,
                       serial_reader_thread,
                       &serial_fd) != 0) {

        perror("[ERROR] pthread_create");

        close(server_fd);
        close(serial_fd);

        return EXIT_FAILURE;
    }

    printf("[INFO] Bridge is running\n");

    while (running) {

        struct sockaddr_in client_address;
        socklen_t client_length =
            sizeof(client_address);

        int client_fd =
            accept(server_fd,
                   (struct sockaddr *)&client_address,
                   &client_length);

        if (client_fd < 0) {

            if (errno == EINTR)
                continue;

            if (!running)
                break;

            perror("[ERROR] accept");
            continue;
        }

        int index = add_client(client_fd);

        if (index < 0) {

            fprintf(stderr,
                    "[WARN] Maximum clients reached; rejecting connection\n");

            close(client_fd);
            continue;
        }

        char ip[INET_ADDRSTRLEN];

        inet_ntop(AF_INET,
                  &client_address.sin_addr,
                  ip,
                  sizeof(ip));

        printf("[INFO] Client %d connected from %s:%d\n",
               index,
               ip,
               ntohs(client_address.sin_port));

        client_context_t *context =
            malloc(sizeof(client_context_t));

        if (!context) {

            fprintf(stderr,
                    "[ERROR] Cannot allocate client context\n");

            remove_client(index);
            continue;
        }

        context->client_index = index;
        context->serial_fd = serial_fd;

        pthread_t thread;

        if (pthread_create(&thread,
                           NULL,
                           client_thread,
                           context) != 0) {

            perror("[ERROR] pthread_create");

            free(context);
            remove_client(index);
            continue;
        }

        pthread_detach(thread);
    }

    running = 0;

    close(server_fd);

    close_all_clients();

    pthread_join(serial_thread, NULL);

    close(serial_fd);

    printf("[INFO] Bridge stopped\n");

    return EXIT_SUCCESS;
}

=========================================================================
8. C CODE DESIGN EXPLANATION
=========================================================================

8.1 MAX_CLIENTS

    #define MAX_CLIENTS 8

Each bridge instance accepts a maximum of eight TCP clients.

GNSS and MCU have independent limits.

Therefore:

    GNSS bridge -> up to 8 clients
    MCU bridge  -> up to 8 clients

8.2 Serial configuration

The UART is configured as:

    115200 baud
    8 data bits
    no parity
    1 stop bit
    no hardware flow control

8.3 TCP server

The program creates:

    IPv4 TCP socket
    INADDR_ANY
    requested TCP port
    listen backlog = 8

Therefore Java clients can connect using:

    <BeaglePlay-IP>:2000

or:

    <BeaglePlay-IP>:2001

8.4 Serial-to-TCP direction

A dedicated serial reader thread continuously reads the UART.

When bytes arrive:

    UART
      |
      v
    serial_reader_thread
      |
      v
    broadcast_to_clients()
      |
      +---- client 1
      +---- client 2
      +---- client 3
      +---- ...
      +---- client 8

The bridge does not parse the bytes.

8.5 TCP-to-Serial direction

Every TCP client has a client thread.

When bytes arrive:

    TCP client
       |
       v
    recv()
       |
       v
    serial_write_mutex
       |
       v
    UART write()

8.6 Why the serial-write mutex exists

The UART is one physical communication channel.

Suppose two TCP clients send data simultaneously:

    Client A -> command A
    Client B -> command B

Without protection, separate threads could write concurrently.

The mutex ensures that only one thread performs a serial write operation
at a time.

This prevents the two write() operations themselves from being executed
simultaneously.

IMPORTANT:
The mutex does NOT implement application-level command/response
synchronization. It only protects the physical UART write operation.

The Java/application layer remains responsible for ensuring that commands
sent to the hardware are logically coordinated.

8.7 One-line and multi-line replies

The bridge has no concept of a line.

For example:

    Hardware sends:
        ABC\r\n

The bridge forwards those bytes.

If hardware sends:

    ABC\r\n
    DEF\r\n
    GHI\r\n

the bridge forwards all received bytes.

There is no assumption that a reply ends at newline.

8.8 200 ms / 2000 ms timing

This bridge does NOT implement:

    wait 200 ms before sending

or:

    wait 2000 ms for response

Those are application protocol decisions.

The current design intentionally provides a transport tunnel.

30. TROUBLESHOOTING
=========================================================================

PROBLEM: "Address already in use"

Example:

    bind port 2000 failed: Address already in use

Find owner:

    sudo ss -lntp | grep ':2000'

    sudo lsof -nP -iTCP:2000 -sTCP:LISTEN

Do not start another copy until the existing listener is identified.

For port 2001 use the same commands with 2001.

PROBLEM: UART is busy

GNSS:

    sudo lsof /dev/ttyS0
    sudo fuser -v /dev/ttyS0

MCU:

    sudo lsof /dev/ttyS3
    sudo fuser -v /dev/ttyS3

Only the intended bridge should own each UART.

PROBLEM: service changes are not taking effect

Run:

    sudo systemctl daemon-reload

Then:

    sudo systemctl restart serial-bridge.service

or:

    sudo systemctl restart mcu_server.service

Verify:

    systemctl show serial-bridge.service -p ExecStart
    systemctl show mcu_server.service -p ExecStart

PROBLEM: program starts and immediately exits

Check:

    systemctl status serial-bridge.service --no-pager

    sudo journalctl -u serial-bridge.service -n 100 --no-pager

or:

    systemctl status mcu_server.service --no-pager

    sudo journalctl -u mcu_server.service -n 100 --no-pager

For manual debugging, stop the service first and run:

    sudo /usr/local/bin/tcp_serial_bridge 2000 /dev/ttyS0

or:

    sudo /usr/local/bin/tcp_serial_bridge 2001 /dev/ttyS3

Do not run the manual instance and systemd instance simultaneously.

31. IMPORTANT OPERATING RULES
=========================================================================

1. Never run two bridge processes on TCP 2000.

2. Never run two bridge processes on TCP 2001.

3. Never allow another process to use /dev/ttyS0 while the GNSS bridge
   owns it.

4. Never allow another process to use /dev/ttyS3 while the MCU bridge
   owns it.

5. Do not change Java TCP ports without a deliberate architecture change.

6. Use systemctl for production operation.

7. Use manual execution only for controlled tests.

8. Keep the original binaries until the new implementation has been
   proven stable.

9. Keep tcp_serial_bridge.c in source control.

10. Record the compiler version and build command.

11. Keep the service files in source control.

12. Keep this document with the project.

35. FINAL UNDERSTANDING FOR A NEW DEVELOPER
=========================================================================

There are two logical services but one common bridge implementation.

GNSS:

    serial-bridge.service
        |
        v
    /usr/local/bin/tcp_serial_bridge 2000 /dev/ttyS0
        |
        +--> TCP 2000
        |
        +--> /dev/ttyS0
        |
        +--> K803

MCU:

    mcu_server.service
        |
        v
    /usr/local/bin/tcp_serial_bridge 2001 /dev/ttyS3
        |
        +--> TCP 2001
        |
        +--> /dev/ttyS3
        |
        +--> MCU

The bridge is a transport layer.

It does not know:
    - what a GNSS command means
    - what an MCU command means
    - whether a response is one line
    - whether a response is multiple lines
    - which Java operation initiated a command

It simply moves bytes:

    TCP -> UART
    UART -> TCP

The physical UART write is protected so that concurrent client threads do
not execute UART writes simultaneously.

Application-level synchronization remains outside this bridge.
